# 股期戰略室維護參考

## 資料來源與口徑

- Goodinfo 週轉率排行必須維持「上市＋上櫃、依當日累積成交量週轉率排序」的口徑，不能用證交所或櫃買中心的單一市場排行取代。
- Goodinfo 只使用已驗證可用的舊版防堵路徑：`page_load_strategy=none`、停用圖片與擴充功能、隱藏 webdriver、固定舊版 UA，並在同一個瀏覽器保留 `CLIENT_KEY`／`REINIT` Cookie。最多兩次導向（第二次加 `RETRY_TS`），總等待約 22 秒；依 DOM 列數判斷形成進度，再以 `lxml` 驗證有效股票代號。Goodinfo 若把 Big5 動態表格誤標成 UTF-8，欄名會變成亂碼，必須改以 4～6 碼股票代號密度辨認代號欄，名稱則交由本地名稱表補回。不得在重試間建立新瀏覽器，也不得改用官方單一市場排行或其他來源備援。
- 股票名稱與代號優先讀取 `stock_names.csv`；快速標籤統一保存為 `名稱(代號)`。
- 期貨成交量、結算行情與保證金以期交所 OpenAPI 為主。官方來源暫時失敗時顯示最後一次成功資料與日期，不得把未知保證金顯示為 0。
- 台股月營收數值以 MOPS 為主；公告日期優先採 FinMind 或可驗證的公司／公開報導來源，並保留人工校正。

## 價格與交易日規則

- 股票當日漲跌停價以該交易日之前一交易日收盤價計算。
- 14:30 前畫面與名稱底色判斷當日漲跌停；14:30 後若顯示隔日預估上下限，必須使用獨立欄位，不可覆蓋當日上下限。
- 當沖進場、停損、目標與支撐壓力點位都不得超出當日合法漲跌停範圍。
- 股票價格級距與漲跌停計算使用 `Decimal`，避免浮點誤差跨過合法 tick。
- 有夜盤的期貨在欄位顯示「日盤+夜盤」；行情 OHLC 與成交量必須屬於同一交易時段或正確的同一交易日，不可混拼。
- Shioaji 1.7 採契約延遲載入；期貨實際契約先用 `api.contracts.futures(root, delivery_month=...)` 查詢，再退回舊式 `api.Contracts.Futures`。期交所 `TX/MTX` 對應 Shioaji `TXF/MXF`。
- 月契約結算日以臺北時間 13:30 為切換點：切換前保留當月，切換後剔除當月、清除其即時排行／報價快取，並將次月重新標為近月。官方最後交易日優先於推算日；只有日期沒有時間時一律補 13:30。
- 「只顯示小型股票期貨」只保留商品類型為股票且標示小型的契約，不可混入 MTX、TMF 或 ETF 期貨。

## Google Sheet 持久化

- 股票快照、期貨戰略室快照、策略訊號、公司事件與費波快速標籤共用現有 Apps Script JSON 儲存，不另建使用者看得到的工作表結構。
- 各資料區塊用自己的 `updated_at` 比較版本。股票較新不代表費波標籤或期貨快照也較新。
- 費波標籤只有五組有效值才可取代既有資料；保存時同時寫入 `fibo_tags_backup`。沒有更新時間的部署預設值不可覆寫雲端值。
- 費波一般啟動採裝置本機標籤優先，避免手機與電腦自動互蓋；使用者按「從 Google Sheet 重新載入」時必須只接受 `fibo_strategy`，雲端失敗不得退回本機後誤報成功。雲端保存必須 POST 成功後再 GET 回讀，五組標籤完全相同才顯示同步成功。
- Apps Script 的 scope 清單必須與程式一致，包含 `stock_strategy`、`fibo_strategy`、`company_events`、`strategy_signals`、`futures_strategy`；參考專案根目錄 `google_apps_script.gs`。
- 期貨本機快照使用 `futures_strategy_cache.json`，不得再把完整 universe 寫入 `config.json`。雲端只保留常用／更新中的契約並限制整體 payload；官方清單可重新抓取，不需保存全部遠月契約。
- 跨裝置保存採讀取、分區合併、寫入、必要時回讀驗證。遠端失敗時保留本機最後成功資料，不寫入空清單。

## UI 與效能

- Streamlit rerun 不應重做不可變歷史資料、啟動多個瀏覽器或重抓所有隱藏分頁；使用有界 TTL、last-known-good 與明確更新按鈕。
- 不可因效能優化而讓已開啟分頁缺資料。延後處理只適用目前確定未使用的重型視覺化或網路呼叫。
- 手機版優先確保表格可水平捲動、按鈕可點、欄位內容不截斷、圖表文字不重疊；桌機版維持緊湊。
- 台股表格顏色固定使用紅色表示上漲／偏多／漲停、綠色表示下跌／偏空／跌停；黃色表示等待或警示、藍色表示資訊／支撐壓力，避免同色同時代表相反含義。
- 選擇權的「模型估值差」是理論價減保守買進價，不可稱為期望損益。一般單買 BC/BP 只有在目標越過損益兩平、目標情境為正、報酬風險比至少 1.25，且模型機率、流動性與價差達標時才可標為建議；放寬層級仍須正目標損益與可達損益兩平，只能標為「小部位試單」，不可冒充一般門檻通過。
