# V1.1 均衡保利

## 適用範圍

股票／期貨主表與獨立分析（當沖、波段）、指數操作計畫（日線／15分K、短波5分K）、選擇權操作計畫（BC、BP、限定風險價差）。以現有有序成交推播及 ModelTracker 推進同一筆模擬交易，不新增行情輪詢、訂閱或計時器，不更動選股、排名與進場門檻。

新訊號使用 V1.1 及 `balanced-1R-v1` 標記；策略版本摘要包含保利政策。沒有標記的既有交易仍依原規則結案，不重算歷史。操作計畫延續舊持倉時，沿用該筆原版本與政策。

## 股票、期貨與指數

- 模擬進場後固定 `R = |模擬進場價 − 原停損價|`，原進／停／目不因保利改寫。
- 僅使用進場後按序收到的有效成交價，最大有利位移達 1R 才啟動；日內高低、過期快照、重新登入後的補查不能倒推啟動。
- 多單保價為「成本保本觸發價」與「已觀察最高價 − 1R」的較高者；空單取成本保本觸發價與「已觀察最低價 + 1R」的較低者。
- 成本價沿用費用設定，求解雙邊手續費、交易稅及不利出場滑價後淨損益至少為零的價位，再向獲利方向對齊合法價格級距。行情尚未提供可執行的成本空間時顯示成本待確認。
- 保價只能向獲利方向移動。有效成交價反向穿越已啟動保價時，以當筆實際觀察價及不利滑價模擬平倉，原因為「保利」。跳空或快速變動仍可能虧損，不以保價回填成交。
- 指數計畫沿用可交易微台契約、每點10元及原口數；加權現貨指數仍作分析背景，不建立虛構現貨成交。

## 選擇權

指數點位不能換算成必然保本的選擇權權利金，因此保利獨立以已成交各腿的實際權利金計算：

- 單買初始1R為實際付出權利金 × 50 × 口數；信用價差初始1R為（履約價寬度 − 實際淨收權利金）× 50 × 口數。均在進場時固定。
- 逐筆使用不晚於觸發時間、相差不超過2秒的各腿成交證據，估算當時出場並扣除每腿雙邊費用、交易稅及不利滑價。
- 最大淨浮盈達1R後啟動；保利淨額為 `max(0, 最大淨浮盈 − 1R)`，只能提高。回落至前次保利淨額時，以當時各腿成交證據模擬平倉。
- 顯示「保 淨額$…」，不偽造一個能保證選擇權成本保本的標的指數價位。BC、BP與價差皆使用相同淨額規則。
- 各腿缺漏時標示資料不足，不推算理論權利金補成交；缺口仍排除有效績效。原標的停損、目標、到期與收盤規則繼續有效。

## 儲存、顯示與版本

- 模型保存保利規則、狀態、初始風險及單位、最大保利浮盈(R)、保價／淨額、啟動／移動時間及出場原因。表格與 Excel 同步顯示；舊資料沒有的欄位保持空白。
- 股期摘要為「已進場｜進…｜停…｜保…｜目…」，持倉以同一模型的凍結價位呈現；未啟動顯示「保 —」。指數／選擇權計畫顯示同一筆保利狀態。
- UI按商品與模式透過 SQLite 索引讀取目前模型，不重新載入全部歷史或計算績效。保利事件走既有非阻塞佇列及 Google Sheet 批次原子合併。
- 事件中保存當時保價，沿用後端既有事件聯集格式；跨裝置回讀時恢復較有利的保價，舊狀態不能放寬保護。不需變更 Apps Script schema。已平倉結果不被後續事件改寫。
- 重啟、序號缺漏及監控中斷沿用原資料缺口規則；恢復保價不代表中斷期間已成功成交，不列為可驗證勝率。

## 驗證

回歸涵蓋1R前後、雙邊成本、空單反向移動、不放寬保價、實際跳空成交虧損、過期與OHLC順序不足、BC／BP／信用價差、缺少權利金、舊版本不變、事件合併與重啟、跨日範圍、模型表格／Excel與AppTest。正式盤中成效仍需累積新版完整成交證據，不以合成測試宣稱提高勝率。
